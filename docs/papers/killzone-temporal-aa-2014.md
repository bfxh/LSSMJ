# Guerrilla · Killzone Shadow Fall 图像质量（GDC 2014, Michal Valient）

> 来源：GDC2014 讲稿 PDF（guerrilla-games.com 官方托管，`killzone_gdc2014.txt` 快照，47MB 原件）。
> 账本：`../analysis/ledger/w7a.jsonl` W7A-060..064（全 paper，5 条）；日期 2026-10-02。

## 要点（每条带账本行）

1. **历史量级**：时间重投影的历史缓冲约含 16 帧数据，用颜色相似度准则，实验过子像素抖动（W7A-060）。
2. **出货组合**：时间重投影 + FXAA，**不用 MSAA**，图像稳定性更好（W7A-061）——2013 主机首发的
   "后滤波 + 时间复用"实配。
3. **数值扩散（糊）**：重投影让图像变糊（MSAA 场景里通常看不见）；对策是回代误差补偿类方法
   （"An Unconditionally Stable MacCormack"）（W7A-062）。
4. **时间复用的红利**：后处理（Bloom/SSAO/体积光/曝光测量）多在低分辨率渲染、对欠采样敏感——
   时间重投影让它们更稳（W7A-063）。
5. **相似度加权公式**：体积光重投影 `result = lerp(current, previous, 0.5*saturate(similarity))`
   （W7A-064）——时间复用的最小可用形态（无速度缓冲也能用的"相似度门控"）。
6. **上下文（同讲稿）**：MSAA+时间重投影是最初方案但因"启动太晚"（launch-title noob mistake）改为
   时间重投影+FXAA；多人模式用 960x1080 交替渲染 + 重投影升到 1920x1080（本波未入账，属补充）。

## 对 LSSMJ 的落点

- **"TAA + FXAA 叠加"有出货先例**（W7A-061）——LSSMJ 的最小集不必把 TAA/FXAA 当互斥二选一：
  可默认 TAA、FXAA 作可叠加/降级档（与 elopezr 记录的 TLOU2 做法一致，W7A-067）。
- **低分辨率渲染 + 时间复用**是这套体系的另一半（W7A-063）：LSSMJ 若引入分辨率缩放，
  时间滤波同时服务 AA 与后处理稳定——一份历史两份收益。
- **糊的量化口径**：数值扩散（W7A-062）与 Karis 的"重投影扩散"（W7A-041）、survey 的"历史重采样"
  （W7A-053）是同一现象的三处独立留档——报告把它并成一条机制账。
