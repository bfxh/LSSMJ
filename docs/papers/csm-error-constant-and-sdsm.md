# 短分析 · CSM 的误差恒定目标与 SDSM 样本驱动分割

> 上游：NVIDIA CSM SDK 文档《Cascaded Shadow Maps》+ Lauritzen 2011 SDSM 论文。
> 账本：`../analysis/ledger/w9a.jsonl` **W9A-033/044/045/046/047/048/049**。只读；抓取 2026-10-03。

## 结论

- **为什么必须分区**：大场景单张阴影图需要"不切实际的分辨率"，故按近密远疏多图分区（`W9A-044/045`）。
- **目标函数**：CSM 的分割目标是让每级承载相同的**屏幕像素误差**（误差恒定，`W9A-046`）——
  与 UE VSM 的 `1 texel = 1 pixel` 同源（`W9A-017`）。这是"质量档定义式"，比"几级 cascade"更本质。
- **两大经典缺陷**：单图在大空间易 acne + aliasing，是 T-PH-05 对拍的两个必测项（`W9A-047`）。
- **分割可优化**：SDSM 按实际深度分布（而非固定对数/均匀分割）分配级（`W9A-033`）——**第一优化点**，
  而不是先把分辨率翻倍。
- **成本随光类型倍增**：点光=6 张 cube（`W9A-048`）；图集化（多光共享大图）是跨引擎共识（`W9A-049`）。

## 对 LSSMJ（T-PH-05 的取舍）

1. 默认档=CSM+PCF，级数 3–4；**分割函数可插拔**（默认误差恒定，进阶 SDSM）。
2. 预算公式以"覆盖半径 + 分辨率 + 级数"三参给档；验收固定覆盖半径测 `texel/pixel`（`W9A-045`）。
3. 多光默认档对点光阴影设数量上限（`W9A-048`），并用图集管理（`W9A-049`）。
4. 对拍项按缺陷清单来：acne、走样、漏光、级间过渡（`W9A-047` + VSM 文档的 transition 讨论）。
