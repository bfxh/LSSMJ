# 短分析 · 无 RT 的接触硬化：SMRT 与 DFSS 两条路线

> 上游：UE 官方文档《Virtual Shadow Maps》的 SMRT 段 +《Distance Field Soft Shadows》段。
> 账本：`../analysis/ledger/w9a.jsonl` **W9A-007/008/010/050/051/052/053/054**。只读；抓取 2026-10-03。

## 质量问题是什么

UE 官方用"遮挡距离→软硬度耦合"来解释 RT/VSM 相对传统阴影图的质量溢价（`W9A-053`）：
传统图缺这条耦合，阴影不会在接触处变锐。**接触硬化（contact hardening）是可信阴影的感知核心**，
质量档验收应以它对拍，而不是以"模糊得多柔"打分（`W9A-052`）。

## 路线 A · SMRT（投影采样）

- 沿光线向 VSM 投影多个采样点做软阴影 + 接触硬化（`W9A-008`）。
- **不做几何求交**⇒对无 RT 硬件友好；软/硬是同一系统的参数档（ray count/samples per ray），
  可一键回退硬阴影保预算（`W9A-007`）。

## 路线 B · DFSS（SDF 追线）

- 从着色点向光源在距离场里追一条射线——**没有硬件 RT 的"软光追阴影"**（`W9A-051`）。
- 近处保留锐利接触阴影、远处软化（`W9A-050`）；远场可由 DFSS 接管（VSM 文档的分工，`W9A-015`）。
- 官方质量序：RT 阴影（硬接触 + 距离软化）> VSM > 传统阴影图（`W9A-052`）。
- 代价面：DFSS 要一套距离场资产与更新链；SMRT 复用 VSM 页与采样预算。

## 对 LSSMJ（T-PH-05/08 的取舍）

1. **默认档**：CSM/PCF 硬边即可，不为软阴影付预算。
2. **质量档（无 RT）**：优先 SMRT（复用页式阴影，`W9A-008`）；大世界远场再评估 DFSS（`W9A-050/051`）。
3. **可选档（有 RT）**：T-PH-08 逐光开 RT 阴影，验收=接触硬化对拍（`W9A-052`）。
4. **产品面**：光移动性（static/stationary/movable）作为显式场景声明，它同时影响性能/观感/设计（`W9A-054`）。
