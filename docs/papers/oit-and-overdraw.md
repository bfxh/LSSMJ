# 顺序、透明与过度绘制（C1 深读 5/7）

> 来源（抓取 2026-10-01，全部 200）：
> McGuire & Bavoil, JCGT 2(2) 2013 加权混合 OIT（`jcgt.org/published/0002/02/09/paper.pdf`）；
> Everitt, NVIDIA 2001《Order-Independent Transparency》（讲稿 PDF）；
> Carpenter 1984 A-buffer（Crossref 元数据）；逐像素链表 OIT（Crossref 元数据，GPU Pro 2）；
> GPU Gems 3 ch23（Off-Screen Particles）、GPU Gems 1 ch28（Graphics Pipeline Performance）/ch29（Efficient Occlusion Culling）；
> Crossref：Hi-Z（SIGGRAPH '93）、MLAA（HPG 2009）；meshoptimizer overdraw 段。
> 账本：`w3a.jsonl` 的 `W3A-037..051`、`W3A-008/009`。

## 1. 它解决什么成本

- **透明正确性 = 顺序正确性**（`W3A-040` 逐字："Correct transparency requires sorted traversal"）：
  对象序硬件下，未排序的透明合成结果是错的。
- **过度绘制（overdraw）**：同像素被多次着色——全屏粒子场景"overdraw 几乎无界，帧率问题随之而来"（`W3A-043`）。

## 2. 四条"顺序"路线

| 路线 | 机制 | 成本/代价 | 锚 |
| --- | --- | --- | --- |
| 排序后混合 | 前到后/后到前遍历 | 需排序，跨多边形不可解 | `W3A-040/047` |
| 深度剥离 | 第 1 遍取最近片元，其后逐遍"剥"下一层（双深度缓冲） | 多遍渲染，成本随层数线性 | `W3A-041` |
| 逐像素链表 | 每像素存片元链表，最后按序合成 | 原子 + 无界存储 | `W3A-042` |
| 加权混合（近似） | 改写合成算子使结果与顺序无关，纯流式 | 颜色近似（非精确） | `W3A-037` |
| A-buffer（祖先） | 每像素多片元列表（AA + 透明同源） | 每像素存储不可控 | `W3A-049` |

加权混合的三条工程优点（论文自述）：**不需特殊硬件**（只要 render-to-texture + 常规 blend，`W3A-038`）、
**内存有界**（3–5 张附加缓冲，`W3A-039`）、消除顺序"跳变"（论文正文）。

## 3. 过度绘制与遮挡的省法

1. **降分辨率离屏**：昂贵粒子渲染到 1/N 尺寸目标再放大合成，"省下大量 overdraw，代价是一些图像处理"（`W3A-044`）。
2. **重排绘制顺序**：meshoptimizer 直接提供 overdraw 优化，阈值 1.05 在顶点缓存效率与 overdraw 间折中（`W3A-008`）；
   但**TBDR 平台（PowerVR/Apple）无收益**（`W3A-009`）。
3. **遮挡剔除**：遮挡查询与 early-z 都要求前到后排序才有效（`W3A-047`）；查询在几何级拒绝、需往返同步，
   early-z 在光栅级逐片元（`W3A-048`）；层次 Z 缓冲是"粗层先淘汰"的鼻祖（`W3A-050`）。
4. **后处理 AA（MLAA）**：几何边缘模式反推覆盖率，是"改不了光栅路径"时的替代（`W3A-051`）。
5. **方法论**：定位瓶颈→削负载→复测（`W3A-045`）；扰动判据示例——改位深看是否帧缓冲带宽受限（`W3A-046`）。

## 4. 对本项目的取舍

- **透明**：候选窗的"半透明"主要是**文字/阴影/背景模糊的合成**，不是多片元叠加。当前路径（预乘 RGBA 逐层合成、
  按内容尺寸缓存阴影）已足够；加权混合（`W3A-037/038/039`）**有界吸收**为"若将来需要大量重叠半透明且排序成本高"的备选，
  启用时必须留档"颜色为近似"。
- **不吸收**：逐像素链表（`W3A-042`，原子/无界存储）、深度剥离（`W3A-041`，多遍）、遮挡查询（`W3A-048`，同步往返）、
  MLAA（`W3A-051`，我们已有超采样）。
- **吸收**：before-after 的**扰动判据模板**（`W3A-046`）与"瓶颈定位三步"（`W3A-045`）并入 `reports/09` 协议；
  "省 overdraw=降分辨率离屏"（`W3A-044`）作为模糊/阴影实现的候选（青简已有盒式模糊，二者不冲突）。
