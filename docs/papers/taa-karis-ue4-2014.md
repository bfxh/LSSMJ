# Karis · High Quality Temporal Supersampling（SIGGRAPH 2014 课程，UE4）

> 来源：SIGGRAPH 2014 Advances in Real-Time Rendering 课程讲稿（PDF，`karis_taa_2014.txt` 快照）。
> 账本：`../analysis/ledger/w7a.jsonl` W7A-027..043（全 paper，17 条）；日期 2026-10-02。

## 要点（每条带账本行）

1. **定位**：TAA 是 UE4 的首选 AA（引擎内叫 Temporal AA，首发 Infiltrator 演示）（W7A-027）。
2. **为什么不用 MSAA**：延迟渲染下太贵（不想每像素多次着色，W7A-028）；且 MSAA 对视三角内走样无效，
   而"三角形内部的走样比边缘更显著"（W7A-029）。
3. **为什么不用空间滤波**：MLAA/FXAA/SMAA 本质是找边缘、治台阶，而这里不是台阶问题；它们没有子像素
   信息、时间上不稳定（W7A-030）。
4. **jitter 与采样**：Halton(2,3) 低差异渐进序列，优于任何硬件 MSAA 采样排序（W7A-031）。
5. **累积**：EMA 用固定存储近似无限样本（W7A-032）；α=2（颜色）/α=5（仅亮度）实用。
6. **累积位置**：tonemap 前物理正确但亮值难收敛，tonemap 后"所有后处理都闪"；最终混合方案=后处理链
   拿到已 AA 的输入（"No more flickering bloom"）（W7A-033）。另有按亮度加权的 tonemap 变体。
7. **重投影**："没有正确速度的运动就会糊"，速度用 16:16 RG——精度要求极高（微小不精确会把静止画面
   拉成条纹）（W7A-034）；讲稿同页要求重投影前先去掉 jitter（未单独入账，见源 `karis_taa_2014.txt:218`）。
8. **边缘**：移动轮廓丢 AA，速度要膨胀取最前片元（W7A-035）。
9. **邻域钳制**：3x3 min/max（W7A-036）；朴素 8 邻居留 3x3 盒状伪影→圆化邻域（W7A-037）；
   clip 取代 clamp（颜色不再在盒角聚集）（W7A-038）。
10. **透明**：TAA 对透明是弱项（单历史+单速度），UE 用 Responsive AA 材质标志（模板+最小反馈）打补丁（W7A-039）。
11. **管线定位**：TAA 是"防火墙"，立在渲染与 Bloom/DOF/Post 之间（W7A-040）。
12. **糊的机制**：滤波核（mip bias 错误→降核/锐化）与"重投影扩散"（重投影落像素外→缩滤波与反馈；
    回代误差补偿 Karis 自述效果不佳）（W7A-041）。
13. **结论与谱系**：2014 即判"生产可用"，但需大量感知调参（W7A-042）；致谢称 Lottes 为共同发明人（W7A-043）。

## 对 LSSMJ 的落点

- **最小 TAA 的接口**：jitter 投影 + 速度缓冲（含膨胀）+ 3x3 圆化 clip + EMA；本讲稿给出全部机理
  与默认量级，与 Playdead 源码互为复核（两源独立给同一做法：速度膨胀、3×3 剪裁、Halton）。
- **管线段位**：TAA 必须早于 bloom/DOF（"防火墙"），且累积点在 tonemap 前后之争有明确结论
  （LSSMJ 的 ACES 链（W6C）上插 TAA：走"后处理前累积"混合方案）。
- **对 UI 档的反面证据**：透明度=时间复用弱项（W7A-040）——UI 位图/文本若走 TAA 必踩；UI 档维持无后处理。
