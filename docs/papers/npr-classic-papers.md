## 谱系读法与对 LSSMJ 的取舍

1. **两个源头**：①"信息传达"动机派（Gooch/Saito：让图更好懂）——与 LSSMJ 的"UI/文本可读性"传统天然契合；②"动画生产"派（X-Toon/Lake/TF2：复刻手绘动画外观）——与用户"三渲二"目标对应。
2. **高光/明暗的"非物理分配"**：Gooch 把明暗压进中调（W8A-081）、Anjyo 风格化高光（W8A-073）——NPR 的公共手法是**重新分配动态范围**，这正是共用内核后唯一必须替换的"最后一层"。
3. **G-buffer 祖型**：Saito 的几何缓冲（W8A-095）说明"几何/可见性/纹理共用、风格算子在图像域"这条路线 1990 年就有——现代 deferred/延迟管线的描边与后效都在其延长线上。
4. **cut 掉的部分**：2D 图像/视频向的 NPR 谱系（Kyprianidis，W8A-085/097）属后效/滤镜轨，**不要**与 3D 管线 NPR 混用结论；LSSMJ 若做"画面滤镜式"风格化可另立小轨。
5. **可吸收清单**：X-Toon 的 2D ramp 与抽象法线（W8A-069，与 UTS/原神 ramp 实践互相印证）；Lake 的三类线（W8A-083）；Gooch 的暖冷双色指示（W8A-094）作为角色档默认补色规则。
