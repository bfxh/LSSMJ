# 短分析 · 动态 GI 的两条现实路线：DDGI 探针 vs SHaRC 世界空间缓存

> 上游：Majercik 等 DDGI（JCGT 8(2) 2019）+ NVIDIA RTXGI（2024–2025 现版 README 与 SHaRC 文档）+
> Godot SDFGI 官方文档 + McGuire 2017 LFP + Keller 1997 Instant Radiosity + Walter 2005 Lightcuts。
> 账本：`../analysis/ledger/w9a.jsonl` **W9A-093..109**（source+paper+doc）。只读；抓取 2026-10-03。

## 路线总图

1. **屏幕空间**（SSGI/SSR 类）：最便宜、最易接，但只在屏内可见（w6b/w6j 已覆盖，本轮不重复）。
2. **探针**：LFP 预计算光场探针（静态场景底座，`W9A-101`）→ **DDGI** 把辐照度探针扩展为
   全辐照度紧凑编码（八面体图集 + 可见性），并明确"动态漫反射"定位（`W9A-093/094/095`）。
   DDGI 对前代的批评：光场探针的预计算本质无法响应动态场景（`W9A-096`）。
3. **世界空间缓存**：RTXGI 现版从"探针辐照度缓存"转向**世界空间辐射度缓存**（命中时查缓存，`W9A-097`）；
   两个成员——NRC（需 Tensor Core）与 **SHaRC（无厂商专属要求，硬件面更宽）**（`W9A-098`）。
   SHaRC 集成结构=两 pass（稀疏追踪填充缓存 → 命中查询加速，`W9A-099`），基线 2^22 项缓存（`W9A-100`）。
4. **灯海/VPL**：Instant Radiosity 是早期主路线（`W9A-102`），Lightcuts 把海量光源组织成树（`W9A-103`）——
   与多光源基建同宗，可复用聚类/光列表设施（但需降噪）。

## 共同纪律

- **"缓存优先"是当代实时 GI 的核心词**：SIGGRAPH 2021 Advances 有《Caching for Real-time Global Illumination》
  专讲（`W9A-104/105`）⇒ 预算应投在缓存表示与更新，而非每帧重算。
- **半分辨率**：Godot 明示 GI 缓冲可半分辨率（4K→1080p 计算，`W9A-107`）——与 AO 同范式，
  目标布局一次设计两用。
- **收敛/更新语义是验收项**：SDFGI 帧数过低会出现可见斑块（splotches，`W9A-108`）；
  静态网格变更后需"离开再回来"或手动开关才重建（`W9A-109`）⇒ 更新触发必须显式化（版本号驱动）。
- **硬件下限**：SDFGI 官方自述"相对吃性能，最好有现代独显"（`W9A-106`）⇒ GI 默认关、质量档开。

## 对 LSSMJ（T-PH-07 的取舍）

1. **等级序**：屏幕空间（已有）→ DDGI 式探针（动态漫反射，6ms 级参考）→ SHaRC 式世界空间缓存（实验性原型）。
2. **范围纪律**：GI 定位词="动态漫反射"（不含镜面/焦散，`W9A-095`），避免范围膨胀。
3. **缓存抽象不锁死探针**：探针只是当前载体，世界空间缓存是下一代形态（`W9A-097`）。
4. **验收**：收敛期伪影 + 动态更新延迟 + 缓存命中率（`W9A-108/109`）。
