## TL;DR（每条带锚）

1. **天空/大气的主线是"预计算 LUT + 低维参数化"**：Bruneton 2008 立下 4D 散射 LUT 正典（W7C-001），Hillaire 2020 反其道——**不用高维 LUT**（W7C-010），改用"低维 LUT + 多散射近似"（W7C-011）；UE 现行实现即后者（W7C-009）。
2. **LUT 的工程纪律被作者显式化**：量纲静态检查+单元测试（W7C-002）、去掉地球 ad-hoc 常量（W7C-003）、单次 Mie 两存储方案并存（W7C-005）——LUT 代码按"可复算库"治理，不是美术常量堆。
3. **地平线伪影与更新成本是 LUT 两条硬约束**：4D 散射 LUT 在地平线精度不足（W7C-014）；LUT 算完后太阳可动、但大气属性变更须重算（W7C-015）——直通"动态天气=重算预算"的判据。
4. **机载透视（aerial perspective）在引擎里是 froxel 缓存**：UE 把收发亮度存进相机视锥体素（W7C-019），Frostbite 用贴视锥的 3D 纹理（默认 32×32×16，W7C-013）——一次求值、全体网格贴回。
5. **模型选择有量化依据**：Bruneton 2016 对 8 个清空模型的评估结论"简化越少越准"（W7C-006/007）；廉价解析档（Preetham W7C-083）与源头模型（Nishita W7C-082）都在谱系里，选谁是可解释的。
6. **水面=空间域与频率域两条线**：Gerstner 波和（4 几何波+~15 法线波，W7C-027/028）与 FFT 谱方法（Tessendorf，W7C-031/032）——前者便宜可控、后者物理统计化；引擎侧用"风+流"屏蔽流体动力学（HDRP W7C-042），并按频段分带（W7C-043）。
7. **水面反射的当代解是屏幕空间光追，且求交要用 2D 对齐的 DDA**：McGuire & Mara 的 2ms 级读数（W7C-034）与"3D 线性步进≠2D 线性步进"的反例（W7C-036）。
8. **粒子的第一约束是 overdraw**（无界，W7C-045）：标准解=分数尺寸离屏目标+深度降采样遮挡（W7C-046/048），代价是图像处理（W7C-047）；排序是可关成本项（W7C-052）。
9. **地形的骨架是 clipmap/四叉树 LOD**：嵌套规则网格增量平移（W7C-056）、空心环渲染（W7C-058）、着色器内 morph 接缝（W7C-059）；公开读数 200 亿采样/355MB/~90fps（2005 硬件口径，W7C-057）；ROAM 属被取代的历史路线（W7C-062）。
10. **植被=批量实例化+确定性放置+广告牌回退**：单 draw call 画草（W7C-067）、相机朝向 billboard 优于三面片（W7C-068）、程序化放置可复现（W7C-069）；"实例化=快"不是本质，收益依平台（W7C-073）。

## 1. 天空 / 大气

### 1.1 模型谱系（选型不是口味问题）

- 源头与解析档：Nishita 1993（W7C-082）→ Preetham 1999 解析日光（W7C-083）→ Bruneton 预计算 2008（W7C-001）→ Hillaire 2020（W7C-009）。
- 量化评估：Bruneton 2016 对 8 模型的评估（W7C-006；期刊定稿=IEEE TVCG，W7C-008）给出结论"简化越少越准"（W7C-007）——**模型选择 = 精度/成本交换，有可引的量化依据**。
- 成本谱系的一手对照：O'Neil 2004 的"去 LUT 解析式"（W7C-016），及其对前作 2D LUT（4 浮点通道、逐顶点多次查表）CPU 成本的批评（W7C-017）。

### 1.2 预计算 LUT 的工程形态（Bruneton 线）

- 2017 重实现是**工程治理样本**：静态类型检查验证量纲（W7C-002）、去地球 ad-hoc 常量（W7C-003）、臭氧层与自定义密度剖面（W7C-004）、单次 Mie 两存储方案同时实现并被测试对比（W7C-005）。
- Frostbite 复述的 Bruneton 谱系：2D 透射率 LUT + 4D 散射 LUT，4D 可迭代出多阶散射（W7C-014 同页上下文）。
- 两条已知硬约束：地平线精度（W7C-014）；太阳可动但大气属性变更须重算 LUT（W7C-015）。

### 1.3 UE 现行形态（Hillaire 线）

- 官方口径：天空在"几个低分辨率 LUT"中求值（逐像素 raymarch 在 4K/8K 下过贵，W7C-018）；LUT 含 Sky-View、Aerial Perspective（froxel）、多散射项（W7C-019）。
- 质量开关全参数化：`r.SkyAtmosphere.SampleCountMax`、`DistanceToCountMax`、`FastSkyLUT`（关掉则慢但伪影少，W7C-020）。
- 论文侧对应：不依赖高维 LUT（W7C-010）、多散射近似（W7C-011）、设备跨度自媒体口径 iPhone 6s→高端 PC（W7C-012）；工程侧材料见作者公开目录（W7C-084）。

- 参考实现（source 级，6 条；自陈是论文配套工程，W7C-021）：
- 参数块（散射/吸收/相函数 g/密度剖面，W7C-022）；LUT 尺寸为编译期常量（W7C-023）；多散射=LUT 间固定迭代（W7C-024）；变步长 SPP 插值（W7C-025）；地形着色器自评"非产品级"（W7C-026）——**参考实现只抄机制，不抄工程品质**。

## 2. 水体

### 2.1 波浪：空间域（Gerstner）与频率域（FFT）

- Gerstner 线（GPU Gems 1 Ch1）：高度=周期波之和（W7C-027）；几何 4 波、法线 ~15 波 2–4 pass 渲进 256² RT（W7C-028）；选 G 波因为**顶点在波峰聚拢**（W7C-029）；按网格频率滤短波（Nyquist，W7C-030）。
- FFT 线（Tessendorf）：以 FFT 为主线的谱方法（W7C-031），patch 尺寸/分辨率可控（W7C-032），FFT=对波之和的快速求值、统计模型决定振幅相位（W7C-033）；综述入口 Darles 2011（W7C-037）。

### 2.2 反射与焦散

- 屏幕空间光追：2ms 级水面反射（W7C-034）、透视正确 DDA 求交（W7C-035）、"3D 线性 ≠ 2D 线性"反例（W7C-036）——P7 软光追的屏幕级判据。
- 焦散：美学驱动路线（W7C-081），前向/后向光线成本对比在章内。

### 2.3 引擎水系统（工程形态）

- UE：spline 建河流/湖泊/海洋，可插拔子系统（W7C-038）；shading 与 mesh 同管线（W7C-039）；单层水=自定义 pass（不透明后、半透前，W7C-040），折射读回可选降采样（W7C-041）。
- Unity HDRP：仿真屏蔽流体动力学，输入=风+流（W7C-042）；三频带（2 涌浪+1 涟漪，W7C-043）；能力按水体类型分档（W7C-044）。

## 5. 重点来源短分析（8 份）

1. **Bruneton & Neyret 2008 + 2017 重实现（W7C-001..005）**：正典路线=多 LUT 预计算（2D 透射率+4D 散射+辐照度），代价是 LUT 维度高、地平线参数化难、属性变更全重算。2017 重实现的价值不在算法而在**治理**：量纲静态检查、单测、去地球常量、两存储方案对比——这是"参数化代码当库治理"的直接样板，与本仓"判据先于改动"同构。
2. **Hillaire 2020（W7C-009..012）**：明确对抗高维 LUT——低维 LUT+参数化+多散射迭代近似；宣称设备跨度大。对 LSSMJ：P5 天空默认走这条路，因为它把"LUT 分辨率/更新频率"变成显式旋钮而不是隐藏成本。
3. **Hillaire 2016 Frostbite 课程（W7C-013..015）**：工程细节最全的一手材料——机载透视 froxel（32×32×16 默认）、4D LUT 地平线精度问题、太阳自由移动 vs 大气属性重算。对 LSSMJ：P5 的 froxel 做法与 P7 的"动态天气=重算预算"都锚在此。
4. **Tessendorf 海面课程笔记（W7C-031..033）**：FFT 谱方法是海面"统计正确"的路线；与 Gerstner 空间域法构成两条线。对 LSSMJ：P5 不上 FFT（4 波 G 波足够），P6+ 大水面再评估——两条线的分界（成本/可控性）本轮已有一手材料。
5. **McGuire & Mara, JCGT 3(4)（W7C-034..036）**：屏幕空间光追的求交范式（2D DDA）+ 2ms 级读数 + 反例（3D 线性步进不等价）。对 LSSMJ：P7 屏幕级反射/折射直接按此实现，反例写进验收（防"朴素步进"返工）。
6. **GPU Gems 3 Ch23 离屏粒子（W7C-045..049）**：粒子成本的完整账（无界 overdraw→分数尺寸离屏+深度降采样，代价=图像处理），且给了 MSAA 兼容坑。对 LSSMJ：P5 粒子标准解，无争议。
7. **GPU Gems 2 Ch2 几何 clipmap（W7C-056..059）**：把大世界地形的数据管理讲得最实的公开材料（窗口/环/morph/公开读数）。对 LSSMJ：P6 地形骨架与"层间过渡在 GPU"的判据来源。
8. **GPU Gems 2 Ch1 虚拟植物（W7C-067..069）**：植被三件事一次讲全——批量（单 draw call 画草）、表示（相机朝向 billboard）、放置（确定性伪随机）。对 LSSMJ：P6 植被的直接模板；与 w6e 的剔除结论拼装（剔除管可见性，放置管数据来源）。
