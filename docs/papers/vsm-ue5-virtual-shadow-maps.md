# 短分析 · UE5 Virtual Shadow Maps（页式虚拟化阴影）

> 上游：Unreal Engine 官方文档《Virtual Shadow Maps》+ SIGGRAPH 2021 Karis 演讲记录。
> 账本：`../analysis/ledger/w9a.jsonl` **W9A-001..023**（doc+source）。只读；抓取 2026-10-03。

## 机制（逐条带锚）

- **虚拟地址空间**：虚拟分辨率 16k×16k（`W9A-001`），页 128×128、页表也 128×128 且带 mip
  （`W9A-018`）——稀疏虚拟纹理那套结构搬到阴影。
- **按需分配**：页只在"屏上像素需要"时分配并渲染，依据深度缓冲分析（`W9A-002`）；精度分配规则是
  "屏幕投影后 1 texel = 1 pixel"的 mip（`W9A-017`）。
- **跨帧缓存**：只有移动物/光才失效（`W9A-003`），官方明说页复用是高性能的**非可选**优化（`W9A-004`），
  演讲侧独立互证"前帧已覆盖区域不再重画"（`W9A-019`）。
- **每光类型不同路径**：方向光用 clipmap（每级同分辨率、覆盖半径翻倍，`W9A-005`）；
  聚光=单张 16k+mip 链；点光=6 面 cube（`W9A-006`）。
- **多视图批处理**：一次提交画所有灯×所有 mip，相对逐视图调用极端可快 100×（`W9A-020`）。
- **成本模型**：成本随分辨率（而非场景复杂度）线性，因为页与精度都按屏上需求分配（`W9A-021`）。
- **软阴影**：SMRT 沿光线投影多个采样点，不做几何求交，可一键回退硬阴影（软/硬=参数档，`W9A-007/008`）。

## 已知代价（官方自陈）

- 单层深度导致漏光，需"缺口填充"启发式（第一遮挡体后方深度外推，`W9A-009`）。
- 骨骼动画/WPO/PDO 材质每帧强制失效阴影页，动画角色是缓存破坏者（`W9A-011`）。
- 多小范围局部光源场景的性能在 2025–2026 版文档里仍标"改进中"（`W9A-012`）。
- 膨胀包围盒+低光角⇒大量无谓页失效，需可视化+紧包围盒（`W9A-013`）。
- 与 Nanite/可变形几何的预计算阴影不兼容；静止光预阴影/per-object inset shadow 要与 VSM 换路（`W9A-014`）。

## 对 LSSMJ（T-PH-05 的取舍）

1. **循序**：先 CSM+PCF 默认档；页式 VSM 作质量档，且**先做帧间缓存再提分辨率**（`W9A-004/021`）。
2. **抽象**：geometry/light 失效语义逐对象可覆写（静态/刚体/每帧三档，对齐 `W9A-043`），
   动态与静态分页池（`W9A-042`）。
3. **验收**：`texel/pixel` 比 + 缓存命中率 + 漏光/走样对拍（`W9A-017/046`）；多小光源场景必须实测（`W9A-012`）。
4. **命名**：代码里 `VirtualShadowMap` 与 `VarianceShadowMap` 必须显式区分（`W9A-022`）。
