# 头发着色：Kajiya-Kay → Marschner → dual scattering（含工程侧双层高光）

- 论文题录（Crossref，2026-10-03 核对）：Kajiya & Kay 1989 `10.1145/74333.74361`（W8A-071）
- 摘要页（Stanford graphics 官方论文页，paper）：`https://graphics.stanford.edu/papers/hair/`（W8A-021..024、086、087）
- 论文题录：Marschner 2003 `10.1145/882262.882345`；Zinke 2008 `10.1145/1360612.1360631`（W8A-078）
- 工程侧（web，旁证）：Unite2017 米哈游分享的头发高光做法（W8A-030、031）
- 账本：npr-hair 8 条

## 要点

1. **基线=Kajiya-Kay 现象模型**：Marschner 摘要开篇即称头发散射"通常"由 Kajiya-Kay 经典模型模拟（W8A-021）——NPR 头发的默认档就是这个（切向光照 + 位移高光）。
2. **实测发现的缺口**：多重镜面高光 + 绕纤维轴旋转的散射变化，Kajiya-Kay 预测不到（W8A-022、023）。
3. **修正模型形态**：发丝=透明椭圆柱 + 吸收内芯 + 倾斜鳞片表面，用圆柱解析散射函数构造实用着色模型（W8A-024），并以照片-渲染对比验收（W8A-087）。
4. **测量方法自述**：在既往测量之外补了 out-of-plane 散射（W8A-086）。
5. **实时化路线**：dual scattering（Zinke 2008）做多重散射的快速近似（W8A-078）。
6. **工程侧（二手）**：米哈游 2017 的头发=各向异性高光（切向光照）+ 高低频双层高光 + Jitter map 抖粗细，且明确"不在贴图上画死"（W8A-030、031）。

## 对 LSSMJ 三渲二轨（P-NPR）的取舍

- **默认档**：Kajiya-Kay 形式（切向高光 + 位移/颜色可调）——实现量级小，与 UTS/原神系的"双层高光"可同构（低频=形状、高频=细节）。
- **质量档**：Marschner 关键项（R/TT/TRT 路径、倾斜鳞片）或双散射近似；代价=面元法线/切向数据与滤波成本。
- **必须记账**：头发需要逐顶点切向帧（tangent frame）与各向异性高光路径；这是共核里 shading 层的一个分支，不触及几何/纹理柱（发丝可仍是卡片/条带几何）。
- **判据**：高光随动态光变化（拒绝贴图美术）——来自工程侧二手，作为美术验收口径可用，但不作为性能/正确性判据。

## 与 photoreal 共核的判据贡献

- 头发是"NPR 与 PBR 分歧最著名"的材质：photoreal 用 Marschner/双散射（物理量），NPR 用 Kajiya-Kay 变体+位移（美术量）。
- 两者**共享**几何（切向帧/卡片）、纹理与阴影设施，只在 shading 函数处分叉——进一步支持"共核 + shading 分支表"。
