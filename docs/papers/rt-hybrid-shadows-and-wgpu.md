## 混合形态（UE 侧）

- **RT 是独立特性，不是全局管线切换**：硬件 RT 按特性接入，阴影可单独开（`W9A-055`）。
- **默认/可选分界**：UE 默认阴影法是 VSM（可控成本+高分辨率），RT 阴影为可选增强（`W9A-056`）。
- **粒度=逐光**：RT 阴影可按光覆写开关（mixed per-light），降级可细到"仅主光用 RT"（`W9A-057`）。
- **终局形态**：Overdrive 档"几乎所有光源都投物理正确软阴影"（`W9A-059`），代价是 RT Core + DLSS 级重建（`W9A-058`）
  ——LSSMJ 视作 P2+ 参考上限，不作近期默认。

## wgpu 侧现实（2026-10 快照）

| 能力 | 状态 | 锚 |
| --- | --- | --- |
| `EXPERIMENTAL_RAY_QUERY` | 存在；Vulkan 原生；实验态 | W9A-110 |
| `EXPERIMENTAL_RAY_TRACING_PIPELINES` | 存在；构造完整 RT 管线（SBT/命中着色）；标注 major bugs/breaking changes | W9A-111/113 |
| ray query 语义 | 着色器内建查询（内联式，非管线式）——单光软阴影的自然形态 | W9A-112 |
| 特性门 | RT 管线可见性被特性门强制（默认拒绝） | W9A-116 |
| 合流重构 | 加速度结构特性被并入 RAY_QUERY（减少特性面、绕 AMD 驱动 bug） | W9A-115 |
| `DEPTH_CLIP_CONTROL` | **正式特性**，面向阴影（遮挡物压入更紧深度范围） | W9A-114 |

## 对 LSSMJ（T-PH-08 的取舍）

1. **架构形态**：RT 阴影=可选成员（不是新管线），粒度逐光；缺特性就地回退 VSM/CSM（与 C10 三级降级同构）。
2. **首选路径**：内联 ray query（`W9A-112`），完整 RT 管线（`W9A-113`）近期不做。
3. **默认档纪律**：实验特性不进默认档（`W9A-110/111`）；锁版本 + 启动特性探测 + 降级金丝雀。
4. **验收**：接触硬化对拍（`W9A-052`）+ 缺特性降级路径可测。
