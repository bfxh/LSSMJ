# Reshetov/Jimenez · MLAA 复盘（HPG 2017 "MLAA from 2009 to 2017"）

> 来源：HPG 2017 研究影响复盘讲稿 PDF（highperformancegraphics.net 存档，`mlaa_retro.txt` 快照）。
> 原始论文（HPG 2009, 页 109-116）在 ACM 付费墙，本波未读（CRC 记录见 W7A-103）。
> 账本：`../analysis/ledger/w7a.jsonl` W7A-089..098（paper）+ 103（doc）；日期 2026-10-02。

## 要点（每条带账本行）

1. **一句话算法**：找分隔不同颜色像素的轴对齐线（W7A-089）→ 重建轮廓（Z/U 形，偏长轮廓解歧）→
   按梯形面积权重在轮廓两侧混色。
2. **定位**：图像增强技术、屏幕空间后处理（W7A-090）——不依赖深度/法线/速度等任何额外输入。
3. **pros**：以"最简解释"重建边缘（lex parsimoniae，W7A-094）；独立于图形管线其余部分（W7A-095）。
4. **cons**：非物理（W7A-091）；边缘是"幻觉"出来的（W7A-092）；奈奎斯特问题（空间与时间域，W7A-093）；
   阈值行为；图像边界处理。
5. **谱系伏笔**：作者列出"若知道更多可做得更好"的信息源——子像素不连续数据、原始 3D 数据、**前帧**、
   领域知识（W7A-096）：前帧=时间 AA 的动机在 MLAA 复盘里被点名。
6. **产业采用**：对照表自述"被游戏开发者广泛采用 + 源码公开"（W7A-098）。
7. **同台课程**：SIGGRAPH 2011《Filtering Approaches for Real-Time Anti-Aliasing》议程（MLAA/SMAA/SRAA/
   DEAA/GBAA/FXAA 3.11 共 17 项）——空间-几何 AA 的全景清单（W7A-097）。
8. **原始论文**：HPG 2009，DOI 10.1145/1572769.1572787（W7A-103）。

## 对 LSSMJ 的落点

- **形态学族的共同失效面**（非物理/幻觉边缘/Nyquist）在选 FXAA/SMAA 时必须写进文档——这是"廉价清晰"
  的价格标签；LSSMJ 的 AA 选型表按"几何 AA vs 着色 AA vs 时间 AA"三栏分别标注失效面。
- **"零额外输入"是集成优势**：MLAA/FXAA/SMAA 1x 不需要管线多输出任何缓冲——LSSMJ 若不建速度缓冲
  （UI 档或无 TAA 的低档），这是唯一可行族。
- **谱系时间线**：MLAA(2009) → FXAA(2011) → SMAA(2012) → TAA(2014+) 可写成一条"信息量递增"的线
  （每代多吃一类信息：形态→形态+子像素→+时间），与本项目的"档位=信息量"设计语言一致。
