## TL;DR（10 条，每条带锚）

1. **高斯是四表示里唯一"天生实时"的外观表示**：3DGS 论文口径 ≥30fps@1080p（`W15A-001`），
   RadSplat 用点/体素预过滤 + 剪枝推到 900+FPS（`W15A-012`）——但数量即成本，剪枝率就是高斯侧的预算旋钮（`W15A-013`）。
2. **粒子↔高斯是零成本恒等边**：PhysGaussian 的物理（MPM）与渲染共用同一组高斯核作离散表示（`W15A-014`），
   并明确免除三角/四面体网格化与 marching cubes（`W15A-015`）——转换图不该把这条边强行走几何枢纽。
3. **高斯→mesh 是全图最弱边**：SuGaR 分钟级、离线（`W15A-004`）；可用形态是 2DGS surfel（视角一致几何，`W15A-005/006`）
   与 GOF 的"高斯诱导四面体 + Marching Tetrahedra"（`W15A-007/008`）。
4. **高斯→体素只有概率占据**：GaussianFormer 的 Gaussian-to-voxel splatting（邻域聚合，`W15A-016`），
   且稀疏高斯比稠密体素省 4–5× 内存（17.8%–24.8%，`W15A-017`）⇒ 该边必须配稀疏结构，稠密化即不成立。
5. **体素→mesh 谱系完整且 Rust 有现成默认档**：MC 1987（`W15A-018`）→ DC hermite 保尖锐特征（`W15A-019`）→
   SurfaceNets 无走样低成本（`W15A-020/021`）；fast-surface-nets 单核 2000 万三角形/秒（`W15A-032`）、
   分块无缝（`W15A-034`）且分块契约是 1-voxel halo（`W15A-035`）。
6. **mesh→体素/SDF 双档**：精度档 = winding number（对自交/破洞缺陷网格稳健，应用清单直指 voxelization 与
   signing distances，`W15A-026/027`）；实时档 = JFA 泛洪（GPGPU 通信范式 + 常数时间近似距离变换，`W15A-022/023`）。
7. **粒子→表面的质量上限 = 各向异性核**：方向由邻域粒子 PCA 给出（`W15A-024`），在平滑表面/细流/尖锐特征上
   显著优于各向同性核（`W15A-025`）⇒ 判据必须测薄流与尖特征，光滑球堆测不出差异。
8. **Rust 生态（2026-10 实测）**：wgpu v30.0.1（`W15A-028`）、`TIMESTAMP_QUERY` 在列（`W15A-030`）、
   mesh shader 仍是实验特性（`W15A-029`）；高斯侧 PLY/SPZ 读入与 GPU compute 抽象有现成 crate
   （`W15A-040..044`）；**稀疏体素格只有读取器**（nanovdb-rs，`W15A-047/048`）⇒ 写侧 + GPU 树是自研缺口。
9. **架构判决（本报告提案，否证条件见 §1 表）**：不建 12 条直连，建三个 aspect 枢纽——
   **几何=隐式场（SDF/占据）、动力学=粒子（物理本体在用户侧，只做数据接缝）、外观=高斯**；
   12 条边分解为 9 条标准腿 + 1 条零成本恒等边（粒子↔高斯）；每条腿 = 一个 wgpu compute pass + 一个机器判据。
10. **门 C22（草案）**：每条腿"体积/质量守恒或解析场对拍 + 同输入逐位确定 + 逐边 GPU 时间上限（timestamp query）"；
    转换不改变默认档可见内容（C17 同族），失败显式降级记账（C10 三级降级同族）。

## 1. 问题定义：四种表示，三个枢纽

四种表示各占一个"aspect"，互转困难的本源是**它们存的不是同一类东西**：

| 表示 | 存什么 | 天然强项 | 天然弱项 | 内存量级 |
| --- | --- | --- | --- | --- |
| 体素/隐式场 | 采样格点上的场值（占据/SDF） | 拓扑免维护、CSG/布尔、GPU 寻址 O(1) | 精度=分辨率；稠密存 O(n³)；拓扑质量受算法影响 | 稠密 256³≈6700 万格；稀疏靠块 |
| 多边形网格 | 顶点+连接关系 | 渲染/UV/碰撞/编辑全链路成熟 | 形变/融合/拓扑变更贵 | 三角形数 O(10⁵–10⁷) |
| 粒子 | 点+速度+半径+材料 | 动力学原生（用户物理引擎的母语） | 表面是重建出来的，不是存的 | O(10⁵–10⁷) |
| 3D 高斯 | μ/Σ/α/SH × N | 外观+实时渲染（`W15A-001/012`） | 无拓扑、无内建表面、物理需外挂（`W15A-014`） | O(10⁵–10⁷)×59B+ |

**12 条有向边的直连图是 N×N 复杂度**，且每条边都会重复发明"另一表示的读取器"。本报告的判决是分解：

```text
            几何枢纽（隐式场：SDF/占据）        外观枢纽（高斯）
              ↑ |  ↑                          ↑ ‖ ↓
   mesh → [腿1] [腿2] → mesh        高斯 ‖（恒等）‖ 粒子
              [腿3]↑↓[腿4]                    ‖
            动力学枢纽（粒子；物理本体在用户侧，只留数据接缝）
```

| 判决 | 依据（锚） | 否证条件 |
| --- | --- | --- |
| 几何枢纽 = 隐式场（SDF/占据，窄带优先） | 两侧入口都有成熟积木：winding number（`W15A-026/027`）与 JFA（`W15A-022/023`）进；MC/SN/MT（`W15A-018..021,008`）出 | 某边绕开场更便宜（如恒等边），则不走枢纽 |
| 动力学枢纽 = 粒子；物理本体不在本项目 | 用户 2026-10-03/10-07 口径；PhysGaussian 证明粒子可直接驱动高斯（`W15A-014/015`） | 用户侧物理引擎暴露的接口形态变化时重审接缝 |
| 外观枢纽 = 高斯；资产侧优先收 surfel/结构化形态 | 2DGS 视角一致（`W15A-005/006`）；Scaffold/Octree 锚点结构（`W15A-009/011`） | 资产全为 mesh 且无采集需求 ⇒ 高斯降为可选 |
| 恒等边不建转换器：粒子=高斯（一个粒子一个核） | `W15A-014/015` | 出现需要拓扑的物理场景（绳/布的结构约束在粒子侧，不受影响） |

## 4. 门 C22（草案）与任务轨 16

**C22 表示转换一致**：每条转换腿有机器判据——几何守恒（体积/质量）或解析场对拍（球/盒/环面的精确 SDF）；
同输入逐位确定（哈希金样，C4 同族）；逐边 GPU 时间上限记档（P95，timestamp query）；
转换失败必须显式降级记账（C10 同族），不许静默吞掉；默认档转换不改变可见内容（C17 同族）。

## 8. CPU 参照实测（2026-10-07，本机 release，rustc 1.99.0；原型 `scratch/conv-proto/`）

四条腿 + 五道机器判据，**GATE ALL PASS**（账本 `W15C-001..009`）：

| 腿 | 实现口径 | 本机读数 | 判据 | 结果 |
| --- | --- | --- | --- | --- |
| 解析场→体素 | 64³ 全格采样 | 0.194 ms / 262144 体素（1351 M/s） | —（腿2/3 的输入） | — |
| mesh→SDF | icosphere(320 面) 暴力点-三角 + 径向出射符号，窄带 ±3H | 104.3 ms / 42408 带内点（391 k点/s） | J2：max_err=0.01331 **恰等于弦差上界** tess_bound=0.01331 ≤ +1.5H=0.06093 | ✅ |
| SDF→mesh | Surface Nets（fast-surface-nets 0.2.1） | **1.182 ms / 21072 三角 ≈ 17.8M tri/s**（与 README 20M/s 口径交叉验证，`W15A-032`） | J3a 体积相对误差 0.00193 ≤ 0.03；J3b χ=2（亏格 0）；J3c 同输入逐位哈希相同（`ea3ea1f97bf4bef9`） | ✅✅✅ |
| 粒子→无符号场 | 4096 Fibonacci 球面粒子，naive 最近粒子（JFA 的 CPU 替身口径） | 107.3 ms / 28032 带内点 | J4：mean_err=0.00548 ≤ 0.05（max 0.02722） | ✅ |

**判据首跑连抓两处仪器错**（被测实现零错——"先量后改"的直接兑现，`W15C-006/007`）：
① 弦差上界量在球面**顶点**上（构造保证恒为 0——"参照量恒零"是仪器错的签名），修正为**面心**；
② 径向出射符号的射线起点误写成 `p`（应为原点）⇒ 全部内部点翻号；换符号方法后误差值逐位相同
（0.18380）成为排除法线索，锁定共享输入路径。修复后 J2 的最坏误差**恰好贴着理论下界走**
（= 弦差上界），余量全部留给分辨率预算——这是解析对拍的理想读数形态。
