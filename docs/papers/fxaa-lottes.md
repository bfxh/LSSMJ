# Lottes/NVIDIA · FXAA 白皮书（2011 版）

> 来源：NVIDIA 官方白皮书 PDF（`fxaa_whitepaper.txt` 快照；封面署 "February 2009"，文档变更史记
> "1.0 25/01/11"——两处日期并存，引用时注明）。账本：`../analysis/ledger/w7a.jsonl`
> W7A-069..080（全 paper，12 条）；日期 2026-10-02。

## 要点（每条带账本行）

1. **成本**：1920x1200 在 GTX480 上 preset 2 低于 1ms（W7A-069）。
2. **形态**：单趟全屏 pass，输入=单采样颜色图（不需要 MSAA 采样面；相对 MSAA 省显存）（W7A-070）。
3. **位置纪律**：必须在 HUD/UI 绘制之前应用（W7A-071）——UI 不被滤波。
4. **颜色空间**：引擎后处理末端、转 LDR/sRGB 之后；在 HDR 上做 FXAA 会"等于关掉 AA"（0 vs 16 强度
   tonemap 后同值的算例）（W7A-072/078）。
5. **目标范围**：三角形边缘 + 着色结果（含子像素/单像素走样，如抖动阴影的斑点）（W7A-074）。
6. **锐度定位**：降走样同时保锐度、把成本压在实用范围内（W7A-075）。
7. **子像素滤波开关**：`FXAA_SUBPIX=2` 强制全开"会糊图"（原文拼写 "Turing"）（W7A-076）；默认档限制
   子像素去除量以保留细特征。
8. **预设**：preset 3 为默认（性能好、无伪影）；0–2 更快但带伪影/降质（W7A-077）。
9. **合并优化**：可与 bloom 合成/调色/噪点合并进同一全屏 pass（W7A-079）；另：能按区域选择性后处理时，
   运动模糊/景深处可跳过 AA（W7A-073）。
10. **谱系（Inspiration 节）**：MLAA(Reshetov)、Practical MLAA(Jimenez)、SRAA、DLAA、Hybrid AA、
    Frameranger 重建 AA、"DX11 Perspective Matrix Jittering Temporal AA"、Deferred MSAA(Pettineo)（W7A-080）。
11. **算法要点（快照内）**：亮度仅用 R/G 通道估算（0.587/0.299）；局部对比度早退；3x3 盒式低通按子像素
    走样量混合；端到端搜索可用各向异性加速（换 dithering 风险）。这些细节在白皮书原文，报告只引用其结论。

## 对 LSSMJ 的落点

- **UI 档答案（最硬的一条外部依据）**：FXAA "在 UI 之前"（W7A-071）——与 Unity 全屏 pass 默认注入点
  （后处理之后、AfterRendering 之前，W7A-145）互证：**后处理链止于 UI 合成**，位图 UI 不入 AA。
- **场景档低档位**：若不做速度缓冲（TAA 前置条件），FXAA 是唯一"零额外输入"的 AA（W7A-070）+ 成本
  <1ms 级（W7A-069）+ 预设档位现成（W7A-077）。
- **颜色空间**：LSSMJ 已有 ACES tonemap（W6C-004/006）；FXAA 必须挂在 tonemap 之后（W7A-072/078 的算例
  说明挂在前面等于白做）。
