## TL;DR（10 条，每条带锚）

1. **虚拟列表的复用池是独立对象，且必须可计量**：VS Code 的 `RowCache` 按 `templateId` 分模板池，
   列表本体只调 `alloc/release`（`W9C-001`），命中/miss 就是可直接记账的指标（`W9C-002`）；
   AndroidX 把回收分四级（AttachedScrap / ChangedScrap / CachedViews / Pool，`W9C-049`），
   干净（未变脏）视图零重绑直接重定位（`W9C-050`），每类型池默认上限 5 且可跨列表共享（`W9C-051`），
   离屏缓存默认 2 条（快速反向滚动靠它，`W9C-052`）。Apple 官方把"离屏即入队、优先返回回收件"
   写成语义（`W9C-073`），并要求调用方**不得跨帧持有条目引用**（`W9C-074`），出池 API 是
   "注册类型 + 按标识出队"两段式（`W9C-075`）。
2. **滚动稳态的重绘集合=可见区∪选区，增量由区间差集驱动**：VS Code 用 `renderTop/renderHeight`
   经 `rangeMap` 定位并把当前选区并入范围（`W9C-003`）；滚动时用区间相对补算插入/删除集合，
   只增删增量行（`W9C-005`）；折叠视口的退化尺寸被显式钳制，防 `start>end` 倒置区间（`W9C-004`）。
   惰性列表的总高是**估计量**（`W9C-043`），验收要计量"实际构建子项数 vs 可见数"（`W9C-042`）。
3. **停靠/工作区的核心契约是"可序列化网格"**：VS Code 的每个可停靠视图实现 `toJSON/fromJSON`
   即参与布局持久化（`W9C-008`），落盘形状=`{root:树(每叶带 data+size), orientation, width, height}`
   （`W9C-009`）；**启动构造与反序列化共用同一路径**，不存在"初始化一套/恢复一套"的双实现（`W9C-010`）。
   Qt-ADS 用 `saveState/restoreState(QByteArray)`（内部 XML，`W9C-037`），版本不符时
   **保持现有布局原样并返回 false**，不做部分恢复（`W9C-038`）。
4. **布局约束必须进树、按节点声明**：VS Code 的网格节点最小宽由子树聚合（`W9C-012`），
   缩小时按 `priority` 决定谁先被压（`W9C-011`）；ImGui 的约束是逐节点的
   （NoDockingSplit / NoResize / NoUndocking，`W9C-031`），并支持 `KeepAliveOnly`（隐藏但保活，`W9C-030`）；
   面板卸载策略要显式参数化——AndroidX 的 `setRecycleChildrenOnDetach`（`W9C-053`）是同一决策的另一端。
5. **布局文件是外部不可信输入**：ImGui 有"加载畸形 ini 会崩"的真实修复记录（`W9C-035`）；
   停靠系统是长周期工程（ImGui docking 分支从 2018 实验起步、issue 至今 159 条评论，`W9C-036`）
   ⇒ LSSMJ 分期落地：**先序列化+拖放重排，后浮动/自动隐藏/popout**。能力面 MVP 照 Qt-ADS 生产样本
   （Scribus 1.7：并排停靠+拖放重排+浮动窗+auto-hide，`W9C-040`）与现代 Web 库（tabs/groups/拖放/浮动，
   popout 后置，`W9C-078`）。
6. **拖放的规范语义是"显式允许才能放置"**：HTML DnD 要求 dragenter/dragover 取消默认，drop 才可达
   （`W9C-019/071`）；VS Code 用私有 MIME 常量集在 `dataTransfer` 传结构化载荷，与系统文件拖拽并存
   （`W9C-020`），并把拖拽行为做成注入接口（`W9C-007`）；悬停 800ms 才触发展开
   （`W9C-018`）；GTK4 把拖源/落点做成事件控制器（`W9C-072`）；Qt 的三要素=载荷格式+源对象+事件序列（`W9C-064`）。
7. **菜单/对话框/分隔条有规范级行为合同**：菜单 `Escape`=关闭整栈级联并把焦点回给调用者（`W9C-065`）；
   模态=焦点陷阱（Tab 不逃）+下层窗口惰性（`W9C-066`），打开先移焦；平台要求至少一个"安全按钮"（`W9C-068`）；
   菜单只承载命令列表，复杂内容改走 dialog/flyout（`W9C-069`）；tooltip 克制——能内联标注就别做悬浮提示（`W9C-070`）；
   分隔条被规范化为可访问控件（带值/范围/方向，可键盘调，`W9C-067`）。
8. **滚动物理有可复算的默认常数**：AOSP `OverScroller` 三状态 SPLINE/CUBIC/BALLISTIC（`W9C-057`），
   减速率 `log(0.78)/log(0.9)≈2.35`——**AOSP 与 Flutter 两处独立实现同式**（`W9C-044/055`）；
   减速段重力常数 2000，但要先按像素密度归一的 `mPhysicalCoeff`（`W9C-056`）；
   样条拐点 `INFLEXION=0.35`（`W9C-045`）；iOS 是独立 simulation 类（弹簧+摩擦+越界，`W9C-047`）；
   拖拽动量投影复用滚动的减速率（`W9C-076`）——**"减速率"应是单一共享参数**。
9. **编辑器级文本缓冲=聚合树，不是字符串/行数组**：Boehm 1995 论文的原始论点即"传统字符串不适合作
   通用文本表示"（`W9C-080`），rope 拼接常态 O(1)（`W9C-081`），并有"逐字符追加不退化成链"的叶合并特例
   （`W9C-082`）；VS Code 的生产样本是 piece tree（十亿字节级，`W9C-013`）：原文只读+变更追加两段式
   （`W9C-014`），旧行数组在 1300 万行时约 600MB/OOM（`W9C-015/022`）⇒ **内存/文件字节比是第一判据**；
   piece table 的随机行访问要从头数换行，必须自带行索引补偿（`W9C-023`）；Zed 的 rope 建在自研
   `sum_tree`（尺寸/维度聚合）上，顺带解决行索引（`W9C-058/059`），块基长阈值与下限成对写死（`W9C-060`）。
   注意年代修正：论文 1995 年的"长度受字长约束"假设在现代已不成立（`W9C-083`）。
10. **命令系统是复杂软件的架构中心**：命令=字符串 id 注册进集中注册表，注册返回可注销句柄（`W9C-016`），
    处理器显式传服务访问器/Context、不捕获全局状态（`W9C-017`）；键位/菜单/命令面板/扩展全部汇到同一
    命令表（`W9C-024`）⇒ 轨 10 的菜单/面板只做**呈现层**。撤销四件套=undo/redo 动作、命令合并
    （compression）、命令宏、干净态（clean 随保存点移动，`W9C-063`）。

## 1. 重点来源短分析（7 份）

### 1.1 VS Code（`868a32d3`）——复杂软件的长样本

- 三件事各有一份生产级样本：**虚拟列表**（`RowCache` + 区间差集重绘，`W9C-001..005`）、
  **工作区网格**（可序列化网格 + priority/min-size，`W9C-008..012`）、**piece tree 文本缓冲**
  （原文只读+变更追加，1300 万行 OOM 教训，`W9C-013..015/022/023`）。
- 命令注册表（`W9C-016/017/024`）与拖拽注入接口（`W9C-007/018/019/020`）给"面板只做呈现层"提供了完整范式。
- 平滑滚动是显式开关（开=125ms，关=0），默认并不平滑（`W9C-006`）——时长是一等参数。

### 1.2 Blender（`d79d62ec`）——面板/工作区状态机

- 面板拖拽有显式状态位 `PANEL_IS_DRAG_DROP`（含子面板，`W9C-025`）；区域分割前先做 allowed 判定
  （非任意区域可切），方向是轴枚举（`W9C-026`）。
- 窗口与工作区/布局绑定，新窗口可复制当前布局（`duplicate_layout`，`W9C-027`）。
- 角部 action zone（分割/切换把手）是**数据化热区**（AZone=矩形+edge 语义），绘制与命中测试共用一份数据，
  且有独立脏标志、只在置位时重算几何（`W9C-028/029`）——停靠交互元素必须并入 damage 体系。

### 1.3 ImGui docking 分支（`64944b45`）——约束与保活

- `KeepAliveOnly` 提供"隐藏但保活"节点（切工作区不销毁面板状态，`W9C-030`）；
- 约束逐节点：NoDockingSplit / NoResize / NoUndocking（`W9C-031`）；
- `PassthruCentralNode` 让中央节点透明并透传输入（`W9C-032`）——与"壳只贴图"的位图契约同形；
- DockSpace 是一等 API（id+尺寸+flags），多 dockspace 可并存（`W9C-033`）；单窗口自动隐藏 tab 条
  （`W9C-034`）；`.ini` 持久化有"加载畸形文件会崩"的真实 bug 史（`W9C-035`）。

### 1.4 Qt Advanced Docking System（`4f4f602c`）——IDE 级停靠的契约面

- 布局持久化=`saveState/restoreState(QByteArray)`（内部 XML，可压缩存 ini，`W9C-037`）；
  版本不符时**无损拒绝**（保持现有布局、不做部分恢复，`W9C-038`）。
- 能力面=并排停靠/拖放重排/浮动窗/auto-hide 四项；Scribus 1.7.0 是生产采用样本（`W9C-040`）。
- 许可 LGPL-2.1（`W9C-039`）⇒ LSSMJ **只读契约不抄代码**：能力面独立实现并登记许可。

### 1.5 Flutter / AndroidX / AOSP / Apple——虚拟化与滚动的跨平台共识

- Flutter：sliver 统一经 `SliverChildDelegate` 惰性构建（`W9C-041`），动机写明"避免创建多余子项"
  （`W9C-042`），惰性列表总高是估计量（`W9C-043`）；Android 档 fling 减速率与 AOSP 同式（`W9C-044`），
  拐点 0.35（`W9C-045`），系数按 0.84×重力以逻辑像素换算（`W9C-046`），iOS 是独立 simulation（`W9C-047`）。
- AndroidX RecyclerView：自述"对大数据集的有限窗口"（`W9C-048`）；四级回收（`W9C-049`）；
  干净视图零重绑（`W9C-050`）；每类型池上限 5、可共享（`W9C-051`）；离屏缓存默认 2（`W9C-052`）；
  `setRecycleChildrenOnDetach` 显式卸载策略（`W9C-053`）。
- AOSP `OverScroller`：三状态（`W9C-054/057`）、减速率与重力常数（`W9C-055/056`）。
- Apple：reuse 队列语义（`W9C-073`）、条目短生命周期契约（`W9C-074`）、两段式出池 API（`W9C-075`）、
  拖拽动量投影复用滚动减速率（`W9C-076`）。
- Qt：视图只拿 model index、不预物化（`W9C-061`），`layoutMode=Batched+batchSize`、`uniformItemSizes`
  两个性能旋钮（`W9C-062`）。

### 1.6 APG / HTML DnD / MS Design——行为合同

- APG menu：Escape=焦点退出+关所有级联（`W9C-065`）；APG dialog-modal：Tab/Shift+Tab 不得出界 +
  打开先移焦（`W9C-066`）；window-splitter 模式把分隔条规范化为可访问控件（值/范围/方向+方向键，`W9C-067`）。
- WHATWG DnD：dragenter/dragover 必须 preventDefault 才允许 drop（`W9C-071`）。
- MS Design：对话框显式解散前阻断交互 + 安全按钮（`W9C-068`）；菜单 flyout 只承载命令列表（`W9C-069`）；
  能内联标注就别做 tooltip（`W9C-070`）。

### 1.7 Zed（`main`）+ Boehm 1995——rope 的两端

- 论文端：rope 的原始动机、O(1) 拼接、叶合并特例、"字符串不适用"论点（`W9C-080/081/082`），
  以及 1995 年字长假设的年代修正（`W9C-083`）。
- 实现端：Zed 把 rope 建在 `sum_tree`（尺寸/维度聚合）上而非裸二叉树（`W9C-058`），
  文本切成定长 Chunk 由树承载聚合尺寸（`W9C-059`），块基长的阈值与下限成对写死（`W9C-060`）。
- 与 VS Code 的 piece tree 构成两条可对拍的路线；两者都要行索引结构来偿随机行访问的代价（`W9C-023/058`）。

### 1.8 现代 Web 三件（TanStack / Dockview / GoldenLayout）——最小 API 与能力面

- TanStack virtual：headless（不出样式）+ virtualizer 对象 + `estimateSize` 回调（`W9C-077`）——
  与 LSSMJ"内核只出可见区间+测量回调、绘制归调用方"的位图契约相容。
- Dockview：能力面=tabs/groups/拖放/浮动/popout（`W9C-078`）——MVP 取前四项，popout 后置。
- GoldenLayout：页面自述"load and save layouts"是标配（`W9C-079`）⇒ **序列化不许后补**。

## 3. 未验证项（缺什么证据）

1. **未运行任何上游代码**：全部为文档/源码静态观察；T-WS-01/05/06 的门（滚动稳态 P95、手感录制回放、
   十万行压测）本轮未做。
2. **VS Code 只取 10 个文件**：`listView.ts` 的滚动/重绘路径与网格布局读得较全，但
   `src/vs/platform/commands` 的注册表实现、编辑器 API 层未逐读——`W9C-016/017` 的"可注销句柄"语义
   来自命令注册表文件本身，服务访问器的完整类型约束未核。
3. **Blender/ImGui 的 C++ 只读局部**：面板/停靠的状态位与约束枚举取到了，但 ImGui 的 dock builder
   内部节点合并/分裂算法未逐行走查；`W9C-035` 的 bug 来自变更日志，未复现。
4. **滚动读数无量级**：AOSP 常数（减速率/重力/拐点）可复算，但"手感"只有常数对齐，
   缺真机 A/B 录制对拍；不同 DPI/鼠标滚轮 vs 触控板的分档未验证。
5. **rope 论文的现代适用性只到 Zed 一例**：Boehm 1995 的实验数据（内存/时间）是老平台口径，
   本报告只取结构性结论（O(1) 拼接/叶合并/不退化），未做现代基准。
6. **Qt-ADS 与现代 Web 停靠库的许可/能力面**：Qt-ADS 许可已核（LGPL-2.1），Dockview/GoldenLayout/TanStack
   只读了页面自述能力与最小 API，各库许可证与版本未逐一登记入台账（W9C-077/078/079 为 doc 级证据）。
7. **无障碍细节只到 APG 合同层**：分隔条可访问控件的平台实现（value/range/direction 的具体映射）
   与读屏器冒烟属 T-UC-02（w9b 的未验证清单同项）。
8. **列表项复用与虚拟化的"跨面板共池"**：AndroidX 有可共享池（`W9C-051`）与卸载开关（`W9C-053`），
   但 LSSMJ 多面板（同屏两列表/停靠切换）时的池归属与内存回收策略未设计——留 T-WS-02 与 T-WS-01 的交界项。
